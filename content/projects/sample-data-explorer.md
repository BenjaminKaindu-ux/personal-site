# Sample Project — Data Explorer

A tiny web app that lets you upload a CSV and explore it — preview, basic summaries, and quick charts. Built in a weekend to learn Streamlit.

## Purpose

Learn to ship something small and useful end-to-end.

## Process

1. Started with a notebook, then moved to a real app
2. Learned that dimensions get expensive quickly — cache aggressively
3. Tested with my own messy data first

## Tools

- Python, Streamlit, pandas
- Plotly for charts

## Lessons

- Uploading files changes your whole app's complexity — design for it from minute one.
- Small, ugly, working beats polished and half-finished.
